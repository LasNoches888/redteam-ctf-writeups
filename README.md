# redteam-ctf-writeups

Шаблоны и разборы CTF-заданий по категориям. Для обучения и портфолио.

## Категории
- web, pwn, crypto, forensics, reversing

Каждый разбор — по шаблону `TEMPLATE.md`: описание → энумерация → эксплуатация → флаг → выводы.

## Дополнительно
- [`INDEX.md`](INDEX.md) — таблица всех разборов.
- `docs/methodology.md` — порядок решения заданий; `docs/tools.md` — инструменты по категориям.
- `challenges/single_byte_xor/` — самодельное crypto-задание с решением (тесты: `python -m unittest discover -s tests`).
