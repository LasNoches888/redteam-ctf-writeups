# Учебное задание: XOR одним байтом (crypto)

Самодельное задание для тренировки — не из реального соревнования.

## Условие
Сообщение зашифровано операцией XOR с одним байтовым ключом. Шифртекст в hex — в файле [`challenge.hex`](challenge.hex).
Найдите ключ и прочитайте сообщение. Флаг имеет вид `flag{...}`.

## Файлы
| Файл | Назначение |
|------|-----------|
| `challenge.hex` | шифртекст, который нужно расшифровать |
| `make_challenge.py` | генератор задания (содержит ответ — не подсматривайте, пока не решили) |
| `solve.py` | эталонное решение: перебор ключей |

## Запуск решения
```bash
python solve.py challenge.hex
```
Разбор — в [`writeups/example_crypto_single_byte_xor.md`](../../writeups/example_crypto_single_byte_xor.md).
