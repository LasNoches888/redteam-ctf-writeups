# Инструменты по категориям

Список для работы с собственными стендами и в рамках правил соревнований.

## Web
| Инструмент | Для чего |
|------------|----------|
| Браузерные DevTools | исходный код, сетевые запросы, cookie, storage |
| `curl` | воспроизводимые запросы из командной строки |
| Burp Suite Community / OWASP ZAP | перехват и изменение запросов |
| `ffuf`, `gobuster` | перебор путей (только в рамках разрешённой области) |

## Crypto
| Инструмент | Для чего |
|------------|----------|
| Python (`hashlib`, `base64`, `binascii`, `itertools`) | быстрые эксперименты |
| CyberChef | цепочки преобразований (base64, hex, XOR) в браузере |
| `openssl` | работа с ключами, сертификатами, хэшами |
| `hashcat`, `john` | восстановление паролей по хэшам — только для хэшей из задания |

## Forensics
| Инструмент | Для чего |
|------------|----------|
| `file`, `strings`, `xxd` | первичный осмотр файла |
| `exiftool` | метаданные изображений и документов |
| `binwalk` | поиск вложенных файлов |
| Wireshark / `tshark` | анализ сетевых дампов |
| Autopsy / `sleuthkit` | разбор образов дисков |

## Reversing и pwn
| Инструмент | Для чего |
|------------|----------|
| Ghidra | дизассемблер и декомпилятор |
| `gdb` (+ pwndbg / GEF) | отладка |
| `objdump`, `readelf`, `checksec` | структура и защиты бинарного файла |
| `pwntools` (Python) | автоматизация взаимодействия с сервисом |

## Среда
- Работайте в виртуальной машине или контейнере, а не на основной системе: файлы заданий могут содержать вредоносный код.
- Для сетевых заданий используйте изолированную сеть (host-only/internal).
